# GitHub branding and presentation

The canonical [README](../README.md) uses a responsive HTML picture element with separate dark and light PNG assets. See [brand directory](../assets/branding/README.md). The title is deliberately concise; the explanation of technology, quickstart, licensing, architecture and documentation takes priority over decorative self-promotion.

## Required checks at upload

- The entire `assets/branding/` folder is uploaded in the first commit.
- Light theme uses `tileo-logo-light.png` (black lettering) and dark theme uses `tileo-logo-dark.png` (white lettering).
- The two PNG source files are left unmodified.
- GitHub organization/repository social-preview images and organization avatars are **not configured by Git**. An organization owner may select and upload authorized brand artwork after repository initialization.
- Founding contribution history remains in [FOUNDING_TEAM.md](../FOUNDING_TEAM.md); no celebratory or unsupported badges are required in the README.
