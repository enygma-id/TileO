# TileO Founding Team

This document preserves the historical founding record of TileO independently from current employment titles, repository permissions, maintainer status, or later organizational changes.

## Founding Organization

**PT Enygma Solusi Negeri (Enygma)** is the Founding Organization and Project Steward of the canonical TileO project.

## Erick Karya — Founder & Founding Vision Lead

**GitHub:** [@erickkarya](https://github.com/erickkarya)  
**Role at founding:** CEO, Enygma

Erick originated and directed the founding vision for TileO within Enygma. He established the project direction: a practical geospatial conversion and distribution toolchain that could become an official Enygma open-source project rather than remain an internal or ad-hoc implementation effort.

Erick is permanently recognized as **Founder** and **Founding Vision Lead** of TileO.

This recognition records project origin and founding direction. It does not imply that Erick personally authored every implementation file.

## Hanafi — Founding Prototype Engineer & First Prototype Initiator

**GitHub:** [@hanafi2274](https://github.com/hanafi2274)

Hanafi was the first person asked by the founding leadership to create a working TileO prototype. That prototype phase established early technical knowledge, feasibility lessons, workflow understanding, and implementation experience that informed the later official project.

Hanafi is permanently recognized as **Founding Prototype Engineer** and **First Prototype Initiator**.

Historical recognition of the prototype does not, by itself, mean that later official source code is line-by-line derived from the prototype. Source authorship and derivative-code attribution must follow actual repository history and provenance evidence.

## Dony — Founding Official Implementation Engineer & Initial Core Developer

**GitHub:** [@donyariefianto](https://github.com/donyariefianto)

Dony subsequently used the technical knowledge and lessons developed through the prototype effort to build the first official TileO implementation for the canonical project.

Dony is permanently recognized as **Founding Official Implementation Engineer** and **Initial Core Developer**.

Source-file authorship must remain traceable through Git history and contribution records. If any prototype code is later reused directly, its original authorship and licensing provenance must be preserved rather than replaced by historical-role labels.

## Founding recognition and current authority

Founding status is permanent historical attribution. Operational authority is not permanent by default.

A founding member may later have no repository access, while a non-founding contributor may later become a Core Maintainer. Neither event changes the historical founding record.

## Changes to this record

Corrections may be made to fix factual errors, names, handles, or documented roles, but the founding record must not be rewritten merely to reflect later organizational hierarchy or repository access.

Material changes require documented approval under [GOVERNANCE.md](GOVERNANCE.md).
