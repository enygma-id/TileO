      Single-band numeric data can be imagery, elevation, or measurements such as temperature and NDVI. Confirm its purpose before conversion.

      Elevation optionsDSM / DTM

      Terrain tiles fill missing pixels and space outside the source with this synthetic height. It is for display only; the COG keeps the original NoData.

      COG retains source pixel values and CRS. Terrain-RGB uses 0.1 m increments; Terrarium uses 1/256 m increments; no vertical datum conversion is performed. If the TIFF does not declare a unit, confirm meters or international feet from its source before creating terrain.

      Recommended: 10–14 for dense vector parcels, 18–20 for raster imagery.

      3D model placementGLB → 3D Tiles

      Coordinates use WGS84. Height is meters above the WGS84 ellipsoid; GLB dimensions are meters.

      Large models are split into spatial tiles with automatic LOD; small models stay as one tile. Completed jobs include modern 3D Tiles 1.1 and an optional B3DM compatibility download for older viewers.

      Choose a GLB to read its location metadata.

      B3DM is enabled by default for GLB jobs. It creates a separate compatibility ZIP and uses additional processing time and disk space.

      Advanced placement

      Use scale only when the source units are not meters.

      Vector tiling options GeoJSON / Shapefile / GPKG

      Density keeps tiles compact and may drop features. Preserve retains more geometry detail and can produce large tiles. Both quantize coordinates.

      Attribute filter (optional)
      Inspect a vector file to choose its columns here — no typing needed.

      All attributes are kept by default. Uncheck columns to shrink tiles.

      Raster tiling options GeoTIFF / Orthophoto

      Recommended: 75–80. Quality 100 turns on lossless mode (2–3× larger file).

      Source options

      Leave empty for georeferenced files. Example: EPSG:32750.

      Recommended Output Settings
      • Max Zoom 18–20: Optimal for high-res drone/orthophotos (5–30 cm/px) without ballooning file size.
      • WebP Quality 75–80: Saves 50–70% disk space with imperceptible visual loss compared to Quality 100.
