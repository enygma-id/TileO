Authentication options
This reference is served entirely by TileO, with no third-party scripts. The complete machine-readable contract is available as OpenAPI YAML.

Authentication

When TILEO_API_TOKEN is configured, every /api/* endpoint except session creation requires either a Bearer token or the HttpOnly browser session cookie. Both credentials grant shared administrator access.

Authorization: Bearer <token>

Create a 12-hour browser session with POST /api/session. End it with POST /api/session/logout. Changing the configured API token invalidates all existing sessions.

Main workflow

POST /api/inspect?filename=…
Upload and inspect raster or vector data.
POST /api/jobs
Create a conversion job.
GET /api/jobs
List jobs and progress.
GET /api/jobs/{id}/download
Download a completed result.
GET /api/jobs/{id}/tiles/{z}/{x}/{y}
Read XYZ tiles.
POST /api/quick/tiff
Stream a GeoTIFF preview without conversion.
POST /api/quick/mbtiles
Preview an existing MBTiles archive.

Request fields, response schemas, formats, and every endpoint are defined in the OpenAPI specification. Command examples are in the API guide.
