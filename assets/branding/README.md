# TileO brand assets

The two raster logos in this folder are provided by the TileO project team and are retained **byte-for-byte**, without recoloring or editing:

| File | Intended background | Usage |
| --- | --- | --- |
| [`tileo-logo-light.png`](tileo-logo-light.png) | GitHub light theme / white backgrounds | Main README, presentation, documentation |
| [`tileo-logo-dark.png`](tileo-logo-dark.png) | GitHub dark theme / dark backgrounds | Main README, presentation, documentation |

Both are transparent PNG images of 512 × 111 px. The project README uses a GitHub-compatible `<picture>` tag to select the appropriate source automatically.

## GitHub settings

The README theme switch is automatic after files are committed. GitHub's *social preview* thumbnail, organization avatar, and repository settings are **not** configured by a Markdown commit; an organization owner may upload an appropriate approved visual separately through the GitHub settings interface.
